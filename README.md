# RezuLens — Frontend

Transparent, open-source ATS resume scorer. Upload a resume + paste a job description, get a score you can actually audit — not a black-box number from a prompt.

RezuLens is part of an [open-source](https://github.com/Ayoub-EDAHLOULI) toolbox of small, free, single-purpose developer and job-search tools.

> **Status:** 3-page site (Home, Score, How it works) wired to the [rezulens-backend](https://github.com/Ayoub-EDAHLOULI/Rezulens-Backend) API, with full multilanguage support (6 languages, including right-to-left for Arabic), dark/light theming, and motion throughout. See [Roadmap](#roadmap).

## Why RezuLens

Most "AI resume scorers" hand your resume to an LLM and return a number with no explanation. RezuLens draws a hard line: **the score and every finding behind it come from deterministic, rule-based analysis** on the backend — keyword matching, structural parsing, section completeness checks. Nothing about the score is generated by a language model. This frontend exists to make that breakdown legible: every module, every check, every match or gap is shown, not summarized away.

No accounts. No persistence. Your resume is uploaded, scored, and discarded — nothing is stored.

## Tech Stack

- **Next.js (App Router)** — routing, server components, and rendering
- **TypeScript** — end to end
- **Tailwind CSS v4** — styling, theming via CSS custom properties (light/dark, switchable and persisted)
- **next-intl** — internationalized routing (`/en`, `/fr`, `/es`, `/de`, `/zh`, `/ar`), translated content, and RTL layout for Arabic
- **Motion** (`motion/react`) — entrance animations, staggered reveals, count-up score numbers, page-transition skeletons

## Getting Started

### Prerequisites
- Node.js 20+
- The [rezulens-backend](https://github.com/Ayoub-EDAHLOULI/Rezulens-Backend) API running (locally or elsewhere)

### Setup
```bash
git clone https://github.com/Ayoub-EDAHLOULI/Rezulens-Frontend.git
cd Rezulens-Frontend
npm install
```

By default the app talks to a backend at `http://127.0.0.1:8000`. To point it elsewhere, copy `.env.local.example` to `.env.local` and set:
```bash
NEXT_PUBLIC_API_URL=https://your-backend.example.com
```

### Run
```bash
npm run dev
```
App available at `http://localhost:3000`, redirecting to your browser's preferred locale (falling back to `/en`).

### Build
```bash
npm run build
npm run start
```

## Pages

| Route | What it is |
|---|---|
| `/` | Landing page — the pitch, a live example score breakdown, and a rules-vs-AI comparison |
| `/score` | Upload a resume + job description, get the real score from the backend |
| `/how-it-works` | Full breakdown of the scoring methodology, module by module, plus a worked example tracing one keyword match end to end |

Every route is locale-prefixed (e.g. `/en/score`, `/ar/how-it-works`); a middleware (`proxy.ts`) redirects unprefixed paths to the visitor's preferred locale.

## Internationalization

Supported locales: English (default), French, Spanish, German, Chinese, Arabic (right-to-left).

- Routing and message loading: `i18n/routing.ts`, `i18n/request.ts`, `i18n/navigation.ts`
- Translated strings: `messages/*.json`, one file per locale, same key structure across all of them
- Backend-generated content (score check details, warnings, error messages returned from `/score`) is **not** translated — that would require i18n work on the backend, which is out of scope for this repo. Everything else — page copy, form labels, navigation, errors this app generates itself — is fully translated.

```
│   ├── icon.png                    # favicon / app icon

│       ├── loading.tsx             # Home page loading skeleton
│       ├── page.tsx                # Home
│       ├── score/
│       │   ├── page.tsx            # Score route (server component, locale metadata)
│       │   ├── loading.tsx         # Score page loading skeleton
│       │   ├── ScoreView.tsx       # upload form + submission logic (client)
│       │   └── components.tsx      # result view, module cards, check lists
│       ├── how-it-works/
│       │   ├── page.tsx
│       │   ├── loading.tsx         # How-it-works loading skeleton
│       │   └── HowItWorksView.tsx
│       ├── components/             # shared UI: Navbar, Footer, ThemeToggle,
│       │                           # LanguageSwitcher, MobileMenu, Reveal,
│       │                           # AnimatedNumber, PageTransitionOverlay, ...
│       └── globals.css             # theme tokens (light/dark), base styles

├── messages/                       # translated strings, one JSON file per locale
├── proxy.ts                        # locale-detection middleware
└── public/                         # static assets (logo, etc.)
```
